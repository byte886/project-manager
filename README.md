# project-manager

个人 / 小团队的轻量项目管理方法论技能：从想法到工单、单项目生命周期、执行治理、文档写作、技能优化，纯 Markdown 模板、全平台通用。

## 使用

这是豆包（及兼容 Agent）的**本地技能（Skill）**。完整能力、触发场景与操作流程见入口文档 **[`SKILL.md`](SKILL.md)**，Agent 命中时首先读取它；下列子目录按需加载，不必一次全读。

## 目录

### 一、项目生命周期（所有项目都用）
- `lifecycle/`：项目生命周期
  - `start/`：启动（initiate）
  - `planning/`：规划（project-templates + idea-to-tickets）
  - `execution/`：执行（status + memory + handoff + batch + governance）
  - `monitor/`：监控（monitor + maintenance-sop）
  - `close/`：收尾（close）

### 二、标准与规范
- `standards/`：标准与规范
  - `project-management-standard.md`：**项目管理总标准**（生命周期/个人项目管理/SOP结构）
  - `document-review-standard.md`：文档评审标准
  - `naming-convention.md`：命名规范
  - `code-style.md`：代码风格
  - `documentation-guide.md`：文档写作指南
  - `agents.md`：AGENTS.md 写法

### 三、特殊类型项目（技能类项目专用）
- `skills/`：技能优化（skill-optimization）
