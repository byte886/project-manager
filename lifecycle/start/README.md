# start · 项目启动

> 新项目第一步做什么？怎么想清楚值不值得做？怎么搭项目骨架？

---

## 这个阶段回答什么问题

| 核心问题 | 通俗解释 |
|---|---|
| 这个项目值不值得做？ | 目标是什么？成功标准是什么？ |
| 项目怎么开头？ | 写什么文档？建什么目录？ |

---

## 目录内容

| 文件 | 作用 |
|---|---|
| `initiate.md` | 项目启动SOP：启动步骤、目录模板、项目总纲模板、创建检查清单 |

---

## 你遇到什么，看哪里

| 你遇到什么情况 | 看哪里 |
|---|---|
| 有个新项目想法，不知道怎么开始 | `initiate.md`（启动SOP章节） |
| 不知道项目目录该怎么组织 | `initiate.md`（推荐目录模板章节） |
| 要写项目总纲，不知道写什么 | `initiate.md`（项目总纲模板章节） |
| 项目骨架建完了，想确认有没有漏 | `initiate.md`（创建Checklist章节） |
| 是商业/收费类项目，想论证值不值得做 | `initiate.md` + 规划目录的商业论证模板 |

---

## 启动阶段核心产出

完成启动阶段后，你应该有：
1. ✅ 一页**项目总纲**（目标/期限/成功标准/负责人）
2. ✅ 基本的**目录骨架**
3. ✅ 标配文件：README、AGENTS、PROFILE、.gitignore
4. ✅ 第一条**决策记录**（为什么做、放弃了什么备选）

> 启动完成后进入**规划阶段**（planning/）：具体怎么做、拆分工单。
