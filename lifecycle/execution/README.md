# execution · 项目执行

> 规划好了，开始做。怎么追踪进度？怎么记问题和决策？怎么交接？怎么跑批量任务？

---

## 这个阶段回答什么问题

| 核心问题 | 通俗解释 |
|---|---|
| 现在做到哪了？ | 任务进度、下一步、完成了什么 |
| 遇到问题怎么办？ | 问题台账、怎么记录、怎么解决 |
| 重要决策怎么留痕？ | 决策记录、工程记忆 |
| 怎么交接？ | 换会话/换AI怎么快速接手 |

## 你遇到什么，看哪里

| 你遇到什么情况 | 看哪里 |
|---|---|
| 要追踪任务进度、记录问题 | `status/active-ledger.md` |
| 要写决策记录、存跨会话结论 | `memory/decision-memory.md` |
| 上下文太长，要开新窗口交接 | `handoff/handover-sop.md` |
| 要派子任务给另一个AI | `handoff/handover-sop.md`（任务交接书章节） |
| 要跑批量任务（多个内容/很久/多工具） | `batch/batch-execution.md` |
| 换了新会话，不知道从哪开始 | `governance/execution-governance.md` |
| 要批量改文件、怕漏改关联文档 | `governance/execution-governance.md` |

## 执行阶段核心原则

1. **进度写在台账里**：不要只放脑子里，写下来才能看到全局。
2. **一次专注一件事**：不要同时开太多任务。
3. **重要决策留痕**：关键选择写下来，以后知道"为什么"。
4. **交接要趁早**：上下文太长就主动交接，不要等完全转不动。

> 执行过程中要**持续监控**（见 monitor/）：定期自查、命中暂停条件要停下来。
