# templates · 模板

> 从想法到工单的各个步骤的模板。

---

## 目录结构

```
templates/
├── consensus.md        # 共识小结模板（clarify的产出）
├── spec.md             # 规范模板（spec的产出）
├── ticket.md           # 工单模板（slice的产出）
└── tickets-index.md    # 工单索引模板
```

---

## 什么时候用

| 你遇到什么 | 用哪个 |
|---|---|
| 做完clarify，要写共识小结 | `consensus.md` |
| 做完spec，要写规范文档 | `spec.md` |
| 做完slice，要拆工单 | `ticket.md` |
| 工单多了，要建索引 | `tickets-index.md` |
