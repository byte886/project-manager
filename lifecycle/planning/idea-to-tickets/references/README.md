# references · 流程参考

> 从想法到工单的各个步骤的详细说明。

---

## 目录结构

```
references/
├── clarify.md             # 拷问澄清（刚开始做项目，先提问把需求问清楚）
├── spec.md                # 共识成规范（问清楚了，写成文档）
├── slice.md               # 垂直拆工单（规范写好了，拆成小工单）
├── explain.md             # 视图讲清楚（改了一堆东西，要跟别人讲清楚）
├── role-collaboration.md   # 角色分工（要派任务给不同的人/AI）
└── playbook.md            # 组合套路（怎么串起来）
```

---

## 什么时候用

| 你遇到什么 | 用哪个 |
|---|---|
| 刚开始做项目，先提问把需求问清楚 | `clarify.md` |
| 问清楚了，写成文档 | `spec.md` |
| 规范写好了，拆成小工单 | `slice.md` |
| 改了一堆东西，要跟别人讲清楚 | `explain.md` |
| 要派任务给不同的人/AI | `role-collaboration.md` |
| 不知道怎么串起来 | `playbook.md` |
