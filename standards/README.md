# standards · 标准与规范

> 项目里"标准是什么、必须遵守什么"都在这里。
> 分两类：**项目管理标准**（管项目怎么推进）和**工程规范**（管怎么写代码/文档/命名）。

---

## 目录内容

| 文件 | 管什么 | 类型 |
|---|---|---|
| `project-management-standard.md` | **项目管理总标准**：5个生命周期阶段、个人项目管理方法、SOP标准结构、各阶段文档清单 | 项目管理标准（总依据） |
| `document-review-standard.md` | 文档评审与优化的标准（怎么评审、按什么标准） | 文档标准 |
| `naming-convention.md` | 文件/目录/代码的命名规范 | 工程规范 |
| `code-style.md` | 代码风格规范 | 工程规范 |
| `documentation-guide.md` | 文档怎么写（落点、分类、AI友好原则） | 工程规范 |
| `agents.md` | AGENTS.md 怎么写 | 工程规范 |

---

## 你遇到什么，用哪个

| 你遇到什么 | 用哪个 |
|---|---|
| 想了解项目管理的标准方法、生命周期怎么分 | `project-management-standard.md` |
| 要评审/优化一批文档，需要标准 | `document-review-standard.md` |
| 要定文件/目录/代码命名 | `naming-convention.md` |
| 要定代码风格 | `code-style.md` |
| 要定文档怎么写 | `documentation-guide.md` |
| 要写 AGENTS.md | `agents.md` |

---

## 和其他目录的区别

- **lifecycle/**：管"项目从启动到收尾具体怎么做"（操作流程），标准依据是 `project-management-standard.md`
- **standards/**：管"标准是什么、必须遵守什么"（规范）
- **skills/**：管"怎么写/优化技能"
