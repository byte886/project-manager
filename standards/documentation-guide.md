# DOCUMENTATION_GUIDE.md（文档写作指南）

> **什么时候用**：只要写文档，就用得上，不分项目大小
> **怎么用**：直接抄这个模板，把你项目的文档风格填进去就行
> **达到什么效果**：所有文档风格统一，AI写的文档直接就能用，不用改

---

## 模板本体

```markdown
# 文档写作指南

> **文档类型**：Governance（治理规范）
> **读者**：AI代理（写文档时必须遵守）

## 一、三层保障
| 层级 | 位置 | 内容 |
|---|---|---|
| 第一层 | README / AGENTS | 核心规则、禁止事项 |
| 第二层 | 子文档 | 详细步骤、参数 |
| 第三层 | 自动化 | 大文件、敏感信息自动拦截 |

## 二、文档分解原则
- 超过500行或跨2个以上领域，就拆成多个文档
- 父文档只放索引链接，不重复子文档内容

## 三、AI友好写作七原则
1. 答案在前：每节开头先给结论
2. 短段落：2-3句一段
3. 标题反映问题：用"如何配置XX"而不是"XX配置"
4. 标题不跳级：H1→H2→H3
5. 命令完整可执行：不只说"运行脚本"
6. 参数用表格：配置项、选项用表格
7. 明确"不要做什么"：反例比正面说明更重要
```
