# CODE_STYLE.md（代码风格规范）

> **什么时候用**：只要写代码，就用得上，不分项目大小
> **怎么用**：直接抄这个模板，把你项目的代码风格填进去就行
> **达到什么效果**：所有代码风格统一，不会一会儿这个写法一会儿那个写法

---

## 模板本体

```markdown
# 代码风格规范

> **文档类型**：Governance（治理规范）
> **读者**：AI代理 + 开发者

## 通用规范
- 所有脚本统一放 `scripts/`，禁止散落在业务目录
- Shell脚本：`set -euo pipefail` 开头
- Python：加类型注解，函数式优先

## Python 规范
- 格式化：black
- Lint：ruff
- 关键约定：导入排序、行宽、异常处理

## 脚本落点受控
- 脚本只把成品写到正式目录
- 运行数据写 `data/`、日志写 `logs/`
- 临时中转写系统临时目录，脚本退出自清
```
