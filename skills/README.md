# skills · 技能类项目优化

> 这是"技能类项目"的特殊规范，不是"普通项目管理"。
> 普通项目管理管所有项目；本目录只管"技能类项目"（比如 multiplatform-media-fetch 这种有 SKILL.md、scripts/、references/ 的项目）。

---

## 目录结构

```
skills/
└── skill-optimization.md     # 技能类项目优化SOP
```

---

## 什么时候用

| 你遇到什么 | 用哪个 |
|---|---|
| 要优化一个技能项目（目录结构、命名、SKILL.md、文档合并） | `skill-optimization.md` |

---

## 和普通项目管理的区别
- **普通项目管理**（lifecycle/execution/）：管所有项目
- **技能优化**（skills/）：只管技能类项目（有 SKILL.md、scripts/、references/ 的项目）
- **工程规范**（standards/）：管写代码、写文档、命名的标准
